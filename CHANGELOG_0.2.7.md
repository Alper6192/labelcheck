# Version 0.2.7

- Produktlabel kann ohne von Florence gelesenen Henkel-Logoanker kalibriert werden.
- Die Transformation wird in diesem Fall aus der gemeinsamen Position von IDH, Gewicht und Batch bestimmt.
- Mindestens zwei geometrisch konsistente Wertfelder sind erforderlich.
- Keine Beschriftungstexte, keine Etikettenränder und keine Bildausschnitte werden verwendet.
- Die Oberfläche zeigt „ohne Logoanker“ statt des irreführenden Werts „Anker 0“.
