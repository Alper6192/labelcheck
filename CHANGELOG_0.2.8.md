# Version 0.2.8

- Produktkalibrierung wählt konsistente IDH-/Gewicht-/Batch-Geometrie statt eines falschen HENKEL-Treffers.
- Ankerlose Produktkalibrierung ist auf plausible, nahezu horizontale Transformationen begrenzt und benötigt drei Kernfeldtreffer.
- Gewichtskandidaten benötigen eine echte Einheit oder eine konfigurierte Standardeinheit.
- Gefundene Werte werden im Vorschaubild an ihrer tatsächlichen Florence-Textbox angezeigt.
- Mindestens drei gefundene Felder verfeinern die Profiltransformation gemeinsam.
