# Start – LabelCheck 0.6.9

1. Projektinhalt in das GitHub-Repository kopieren.
2. `public/config/label-profiles.json` enthält den zuletzt bereitgestellten Profilstand mit Intern2-Sondererkennung und Tesla.
3. Commit und Push auf `main`.
4. Unter GitHub Actions den Workflow **GitHub Pages veröffentlichen** vollständig durchlaufen lassen.
5. Scanner: `https://alper6192.github.io/labelcheck/?v=068`
6. Editor: `https://alper6192.github.io/labelcheck/editor.html?v=068`

Auf Mobilgeräten ist der stabile OCR-Modus standardmäßig aktiv.
